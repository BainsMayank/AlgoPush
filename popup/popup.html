So AlgoPush shows it for you. Every Accepted submission, written to your own repository the moment the judge says so — and your friends see the streak you are keeping.

Connect GitHub

AlgoPush installs as a GitHub App. GitHub gives you a short code to enter on its own screen, then you choose the exact repository AlgoPush may write to. There is no access token to generate.
